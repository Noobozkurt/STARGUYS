# Star-Guys Battle

This is a cartoon battle game for Android, written in Kotlin. It is based on the design document *Star-Guys Battle — Modes, personnages, assets et technique*. The game combines Brawl Stars-style heroes and supers, PUBG-style loot, and Fall Guys-style physics chaos.

All of the graphics, sounds and music are generated by code, so the project has no image or audio files. It has no third-party libraries either and builds with plain Android Studio.

## Open and play in Android Studio

1. Open Android Studio (Ladybug 2024.2 or newer).
2. Choose **File ▸ Open** and select this `Star-Guy` folder (the one that contains `settings.gradle.kts`).
3. Let Gradle sync. The first sync downloads Gradle 8.11 and the Android Gradle Plugin.
   - If Studio asks to install **Android SDK Platform 34**, accept.
4. Plug in an Android phone with **USB debugging** enabled (Settings ▸ About phone ▸ tap "Build number" 7 times ▸ Developer options ▸ USB debugging), or start an emulator.
5. Press **Run ▶** (the `app` configuration). The game starts in landscape.

The game needs Android 7.0 (API 24) or newer. A phone in landscape works best.

### Build an APK from the command line
```bash
./gradlew assembleDebug
```
The APK is created at `app/build/outputs/apk/debug/app-debug.apk`. You can copy it to a phone and install it, provided "install unknown apps" is allowed.

### Run the automated play-test
```bash
./gradlew testDebugUnitTest
```
`SimTest` plays every mode for 30 to 150 simulated seconds. The player's slot is also driven by a bot, and the test runs the full draw path to catch crashes.

## Local multiplayer (Wi-Fi and Bluetooth)
Main menu ▸ **MULTIJOUEUR**:
- **Wi-Fi local** supports up to 8 players. All phones must be on the same Wi-Fi network, or connected to one phone's hotspot. One player taps **Créer une partie**. The others tap **Rejoindre**, and the game appears in the list. If it doesn't, use **IP manuelle** with the address shown on the host's screen.
- **Bluetooth** supports up to 4 players and needs no Wi-Fi. The host taps **Créer une partie** and accepts the "visible" prompt. The others tap **Rejoindre** and pick the host's phone. Android asks for the Bluetooth permissions the first time.
- In the room (*salon*), the host chooses the mode, the biome, the bot difficulty, and whether humans play as **teammates or opponents**. Each player picks their own hero. Bots fill the empty slots.

The networking uses **deterministic lockstep**: every phone runs the same simulation and only the players' touch inputs are exchanged. It uses very little bandwidth, so it works well over Bluetooth. If a player disconnects, a bot takes over their hero. `NetTest` runs a real host and client over a socket and checks that both simulations stay bit-identical. It also checks that all 19 modes are deterministic from every player's point of view.

## Controls (touch)
| Control | Action |
|---|---|
| Left half of the screen | Virtual joystick: move |
| Red stick (bottom right) | Drag to aim and release to shoot. A quick tap auto-aims. Auto weapons fire while held. |
| Yellow star | Super. Drag to aim, or tap to auto-aim. It charges when you deal damage. |
| Green arrow | Jump. Press it again in the air to **dive**, Fall Guys style. |
| Blue button | Gadget, when you have one |
| Pink button | Consumable, when you have one |
| Orange button | Contextual action: get in or out of a vehicle, swap a weapon, use a zipline, cannon or claw machine, build a barricade, change disguise… |
| `!` | Ping: tap `!`, then tap the spot to signal, either on the screen or on the minimap. Your team sees a beacon. |
| ⏸ | Pause or quit |

## What's in the game (compared with the design doc)

**Modes: the 18 modes plus the base battle royale**
- Classic: **Battle Royale** with a parachute drop, a shrinking storm, loot, vehicles and 15 to 40 players (set in Settings).
- PvP: **Zone inversée** (rising slime, climb!), **Gravité zéro** (space station, ring-outs, 3 lives, knockback grows with damage %), **Chasseur et proies** (1 hunter against 15 unarmed beans, with hidden weapons), **Roi de la colline mouvante** (the hill rides a cart around a rail loop), **Braquage** (4v4 gold heist, carrying a bar slows you), **Arène des armes** (gun game, 11 weapons ending with the golden pan), **Capture du drapeau** (3v3, the flags sit behind obstacle courses), **Infection slime**, **Football explosif** (shoot the giant ball), **Cache-cache props** (prop hunt with 7 disguises).
- PvE co-op: **Défense de château** (10 waves, barricades and turrets between waves, two bosses), **Évasion** (a procedurally generated escape course with a self-destruct wave), **Raid multi-boss** (3 rooms with a mini-boss each, then the final boss).
- Fun: **Mode géant**, **Pluie de météorites**, **Tous au corps à corps** (hammer, sword, pan), **Mode miroir** (controls flip at random).
- **Atelier joueur (Creative)**: a full level editor with tiles, heights, 14 interactive objects and 34 decorations. It has 6 save slots. You can test a level as an **Arena** or a **Race**, and **share it as a text code** through any messaging app. **Import** reads the code from the clipboard.

**Characters**
- 12 heroes, each with an attack and a super: Gumbo, Volt, Mama Tortue, Pixel, Chef Boulette, Capitaine Bouchon, Nuage, Rex-Tracteur, Lady Mousse, Glitch, Mamie Météo and Bolt le Toaster. Each has 3 color skins.
- AI enemies: Gluants (they split), Drones-mouches, Robots-poubelles and kamikaze garden gnomes, plus giant crabs on the beach.
- 4 bosses with attack patterns and a phase 2: Roi Gélatine, Méga-Marteau, La Pieuvre-Grue and Le Chef Cuistot Géant.

**Items**
- 10 weapons: magnet rifle, foam cannon (makes platforms), grapple crossbow, glitter flamethrower, giant boomerang, confetti blunderbuss (blinds), bubble pistol (traps), toy railgun (goes through thin walls), suction-cup launcher (sticky mine) and baseball bat (reflects shots). There are also 3 melee weapons and the hunter's blaster.
- 9 gadgets: trampoline, inflatable wall, bean decoy, toy turret, jetpack, emergency parachute, banana peel, glue grenade and radar.
- 4 consumables: speed soda, lollipop, bubble shield and giant mushroom.

**Vehicles (7)**: bumper car, inflatable duck (water), rocket unicycle (hard to control), construction crane (grabs players), hot-air balloon (sniper view and range), toy tank, and the roller-coaster wagon on rails.

**Biomes (8, plus the classic meadow)**: amusement park (Ferris wheel, rails, bumper cars, stalls), toy factory (conveyor belts, presses, paint vats), snowy mountain (ice and avalanches), tropical beach (water, palms, boats, crabs), giant kitchen, space station (low gravity), jelly volcano (bouncy jelly lava) and haunted swamp (fog of war with lanterns).

**Interactive props**: jump pads, fans, speed pads, swinging doors, collapsing floors, conveyor belts, player cannons, explosive barrels, slime canisters, fire hydrants (the water jet pushes you), ziplines, ladders, destructible cardboard and glass, claw machines (random weapon), elevators and moving platforms, teleporters, pendulum blades, giant mouse traps and spinning bars. There are also more than 30 decorative props.

**Graphics**: the characters and props use volumetric 3D-style toon shading, with light from the top-left, shaded volumes and specular highlights. Heroes lean into their runs and show their **back** when walking away from the camera. The ground uses procedurally painted textures for each biome (grass blades, paving, metal plates, snow sparkles…). Walls cast soft **drop shadows**, and the game adds contact shadows, glowing projectiles, explosion flashes and a cinematic vignette. The colors come from the **Tailwind CSS palette**. Tailwind is a web CSS framework and can't run inside a native Android game, so its exact color scales were ported (`core/Tw.kt`) along with Tailwind-style gradient buttons and frosted-glass panels. Heroes are chosen on a **3D rotating wheel**: drag or fling it, or tap a hero.

**UI and effects**: bouncing damage numbers, hit markers, pings, a kill cam, spectator mode, a victory podium with an emote, confetti on eliminations, weapon trails, shockwaves, cartoon smoke and stun stars. The look is bloodless and cel-shaded with ink outlines. The game also has a minimap, a kill feed, and progression (coins, trophies, XP, levels, skins).

## What is *not* included, and why
The design doc recommends Unity, Photon/Fish-Networking, dedicated servers (Edgegap, Multiplay) and PlayFab or Nakama. All of these need paid accounts, server hosting and API keys, so **online play over the Internet** is not included. Multiplayer is **local** (Wi-Fi and Bluetooth), and bots fill the remaining slots.

## Ready-made APK
`apk/StarGuysBattle.apk` is a prebuilt debug build of this exact code. Copy it to an Android phone (Android 7+) and open it to install.

## Project structure
```
app/src/main/java/com/starguys/battle/
  MainActivity.kt        fullscreen activity
  core/                  game loop (SurfaceView + thread), drawing helpers, synthesized audio, save data
  game/                  engine: tiles/maps, physics bodies, fighters, heroes & art, weapons, supers,
                         projectiles, props, vehicles, mobs & bosses, bots (A* pathfinding), FX, HUD
  modes/                 the 19 game modes
  net/                   local multiplayer: framed links, host/client sessions, lockstep, Wi-Fi & Bluetooth transports
  creative/              level format (share codes) and the editor
  ui/                    menus, lobby, hero select, settings, results
```
